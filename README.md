# Vektor Q3 – Mathe Trainer

Mobile-first PWA für GitHub Pages und iPad.

## Enthalten
- Lernkompendium für zentrale Q3-Themen
- Aufgaben-Generator mit drei Niveaus
- Sofortiges Feedback + Hinweise
- Erklärstudio: eigene Erklärung schreiben und anhand einfacher Kriterien prüfen
- 60-Sekunden-Erklär-Challenges
- lokaler Lernfortschritt
- Dark Mode
- Offline-Unterstützung per Service Worker
- ohne Backend, ohne Account, ohne externe Bibliotheken

## GitHub Pages
1. Alle Dateien in ein GitHub-Repository laden.
2. Repository → Settings → Pages.
3. Als Quelle `Deploy from a branch`, Branch `main`, Ordner `/ (root)` auswählen.
4. Nach dem Deployment die Pages-Adresse in Safari auf dem iPad öffnen.
5. Teilen → „Zum Home-Bildschirm“.

Der Lernfortschritt bleibt auf dem jeweiligen Gerät im Browser gespeichert.
